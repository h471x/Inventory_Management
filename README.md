# A Simple GUI App with Qt

This project is a simple graphical application developed with Qt.

## Installation

1. **Clone the repository**

	```bash
	git clone https://github.com/hatixntsoa/inventory.management.git
	cd inventory.management
	```

2. **Open the project in Qt Creator (Qt5)**

	- Launch Qt Creator.
	- Click on "Open Project" and select the `.pro` file or the cloned project folder.
	- Make sure to use a kit based on Qt5.

3. **Build and run the application**

	- Click on "Build" then "Run" in Qt Creator.

## Prerequisites

- Qt5 and Qt Creator installed on your system.
